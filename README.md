# GuhBot.Discord

GuhBot is a Discord bot with fun, game, image, info, and moderation commands. This repository is the TypeScript rewrite of the original Python bot, GuhBot.Prime. It uses [discord.ts (discordx)](https://discordx.js.org/) on top of [discord.js](https://discord.js.org/), with slash commands and embed replies. The [Command Reference](docs/commands.md) lists every command and how it maps to the original bot.

The bot runs in a container on any machine with Docker, such as a Raspberry Pi or a home server. It builds on the [template-service](docs/guides/template-usage.md) conventions for the dev container, image publishing, and Docker Compose deployment.

## Development

Run these commands from the repository root inside the [dev container](.devcontainer/README.md). The container's setup script runs `npm ci` to install dependencies.

1. Copy `.env.example` to `.env`. Set `DISCORD_TOKEN` to the test bot's token and `DEV_GUILD_ID` to your test server's ID, as [Discord Setup](docs/guides/discord-setup.md) describes.
2. Build and start the bot.

   ```sh
   npm run dev
   ```

   The bot registers its commands in the test server when it logs in. Press Ctrl+C to stop it.

| Command | Purpose |
| --- | --- |
| `npm run dev` | Compile and start the bot with the settings in `.env` |
| `npm run build` | Compile `src/` to `build/` |
| `npm start` | Start the compiled bot |
| `npm run check` | Type check the bot and the tests, and check formatting, as continuous integration does |
| `npm run test:archivist:discord` | Run the Archivist command tests described in [Tests](tests/README.md) |
| `npm run format` | Format the code with Prettier |

The bot keeps AFK statuses in a SQLite database at `data/guhbot.db`. The container image stores it in the `/data` volume instead.

To run the bot exactly as a server would, run `docker compose up -d --build` from the repository root.

## Included Checks

Pull requests run the repository checks described in [Tools](tools/README.md), the `check/typescript` job, which runs `npm run check` and `npm run build`, and the `archivist/discord` job, which runs the Archivist command tests. Run `npm run check`, `npm run test:archivist:discord`, and `python3 tools/scripts/run_checks.py` before requesting review.
